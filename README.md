# IFL Customizer — Interactive Demo

The clickable design mockup of IFL Watches' Customizer V2 — a static, password-gated GitHub Pages prototype used to preview and share the customizer UX with the team and stakeholders.

> **Mockup, not the app.** Front-end only (HTML/CSS/JS, no backend). The production app is `deviflw/iflw-customizer`; the broader design/research family lives in `deviflw/iflw-customizer-v2` (`mockup/`). This repo is the published, StatiCrypt-gated demo build (password kept with the team, not in this public repo).

## Contents

- `index.html` — demo entry point
- `shared/` — `customizer.js`, `v2-light.js`, `styles.css`, `v2-light.css` (the V2 "light" prototype)
- `assets/` — hero images + service art

The demo pulls real watch names/data so it previews against the actual catalogue rather than placeholders.

## It is not the app

For the live customizer (Cart Transform, Custom Concept, extensions), see `deviflw/iflw-customizer`.
